# 國王密令 King's Quest — 第三波 PC22 中文說明書

本檔是第三波資訊文化事業（台北）1990 年代發行的《國王密令》（King's Quest）盒裝中文說明書
逐頁判讀後的文字版。掃描原件在同目錄 `第三波PC22-國王密令(國王密使)/`（14 頁 JPG）。

原始說明書封面標題作**「國王密令」**，副標 KING'S QUEST；坊間另有「國王密使」的叫法。
本專案的譯名一律以這份說明書為準。

---

## 壹、硬體需求（原文照錄，具年代參考價值）

- MPF-PC、IBM-PC 或其相容性 16 位元電腦
- 主記憶容量 128KB 以上
- 擴充槽上加 CGA（Color Graphics Adapter），並將主機板 SW 上的 switch 調至
  Color Graphic Mode 位置（通常為 SW1-5 ON、SW1-6 OFF）
- 顯示器接法有三：RGB monitor 接 CGA 的 9 pin D type connector；8 位元電腦用的複合信號
  顯示器接 CGA 的 RCA connector（梅花座）；家用電視經 RF modulator 接梅花座或 4 pin berg 接頭
- MPF-PC 舊型採用 BROM 版本之機型者，請先載入 DIOS，再以 CTRL-ALT-DEL 啟動本磁片

說明書另提醒 MGA（Hercules）用戶：畫面可能垂直跳動，需調整顯示器背面的 V-HOLD；
單色顯示器因 CRT 螢光劑材質，畫面移動時會有殘影（類似彗星的尾巴），此為正常現象。

## 貳、故事背景

很久很久以前，當猛獸蠻族仍橫行於世的動盪時期，唯有愛德華國王統治之下的**戴凡確王國**
呈現一片富庶繁榮的景象。但陰霾卻存在國王和皇后心中——因為他們沒有孩子來繼承王位。

一個亮麗的清晨，國王和皇后正在花園裡散步，突然有一位法術高強的**巫師**出現在他們面前，
說：「我可以施魔咒為你們帶來一位孩子，我僅需要你們那面鏡子。」

巫師要求的那面**魔鏡**具有能夠預見未來的魔力，也因此使王國保持富庶繁榮。國王和皇后回到
寢宮問魔鏡，希望能得到答案。他們在魔鏡深處隱約看見一位頭戴金冠如王子般的影像，一想到
這位年輕人將成為他們的兒子，便很高興地將魔鏡給了巫師。巫師帶著魔鏡返回住所，並派了最
兇猛的野獸看顧魔鏡。

幾個月過去，不但沒有王子的消息，反而因為沒有魔鏡的協助，王國遭受到四百年來第一次提早
到來的秋季暴雨，損失了一年農作收成。人民只好緊腰帶過日子，飢荒帶來了致命的瘟疫，連皇后
也遭到病魔的襲擊。

在皇后病倒後的第四天，有個**小矮人**來到皇宮對已絕望的國王說：「我跋涉萬里為您帶來這種
只有矮人族才知道的神奇樹根，它可以治癒所有的瘟疫。」小矮人用樹根輕觸一下皇后的嘴唇，
皇后立刻睜開眼睛，並對國王微笑。在驚訝之餘，國王答應以任何代價來換取這神奇的樹根。

小矮人面帶微笑地回答：「我只要您父親在臨終前交付給您的那具**盾牌**。」

這具**靈盾**傳統上是由戴凡確王國的統治者在戰爭中所持用的，只要國王持有這一個靈盾，便能夠
刀槍不入，而且他的軍隊也將戰無不勝、攻無不克；因此，五百年來，沒有任何一次外來的進襲
足以威脅到戴凡確王國。

為了妻子和臣民的生命，國王忍痛將靈盾交予小矮人。小矮人拿走了靈盾後，便在地上找個隱密的
洞，將靈盾密藏起來。想不到皇后吃掉了那枝樹根後不但毫無起色，且日漸衰弱，終於逝世了。
王國的教堂敲起了悲悼的喪鐘，國王也發誓一定要對這弄虛假的小矮人進行報復。當王國失去靈盾
的消息為鄰國所悉知，從此外患不斷。

幾年後，孤獨的國王騎馬外出時，從狼群中救了一位年輕漂亮的小姐，她對國王說：「我是**肯伯倫
王國**的公主，我們在旅途中遭狼群的襲擊，侍衛們丟下我逃命去了，我十分感激您的救命大恩。」

國王被公主的美貌迷住了，便向公主求婚，而她也很高興地答應了，整個王國開始熱烈的慶祝，
並著手準備一場盛大的婚禮和慶典。

婚禮的前夕公主向國王道晚安時，將掛在國王腰帶上的鑰匙圈順手拿走了。不久之後，皇室珠寶的
管理員發現寶庫的門是開著的，而公主就站在裡面，手上拿著一個小的**金盒子**，且突然變成了
**巫婆**，她抓住金盒子，跨上她的掃把，從敞開的窗戶中揚長而去。

當國王聽到這個消息時，絕望地哭了起來，因為那個金盒子是一個聚寶盆，也是王國僅存的一件
寶物。沒有了這個金盒，國王將無法買更多的食物，也無法再付薪餉給士兵們了。

幾年後，王國變得既窮且弱，愛德華國王已經老衰了。他惟恐在死後整個國家會陷入更大動亂不安
的情況，於是派人將**格拉漢爵士**找來。

國王說：「格拉漢爵士，你是我王國中最驍勇、最忠誠的騎士。在很久以前，我便已在魔鏡中看到
你的影像，並認為我看到的，便是王位的繼承人。為了證明你足以繼承我的王位，我命令你即刻
出發，務必要將那三件被詐騙、偷竊奪走的寶物取回來。只要能達成這個使命，你將繼承王位。
如果你不幸失敗了，則你可愛的家邦會更形衰弱，而且將使它受到鄰邦的侵略和征服。祝你順利
取回寶物，凱旋榮歸。」

## 參、遊戲方法

### 特殊控制鍵

| 鍵 | 作用 |
|---|---|
| ESC | 暫停遊戲 |
| TAB | 檢視格拉漢爵士的攜帶物品及得分 |
| 7 | 重新遊戲 |
| 9 | 重新顯示上個指令 |
| −（減號） | 俯身／回復 |
| 0 | 跳躍 |
| =（等號） | 游泳 |

### 位移控制鍵（數字鍵盤）

```
      西北      北      東北
       7        8        9
     home       ↑      PgUp
  西   4        5        6   東
       ←                 →
       1        2        3
      End       ↓      PgDn
      西南      南      東南
```

### 如何下命令

遊戲剛開始時設定為複合信號顯示（電視或 Apple 用 monitor）；若您用的 monitor 為 RGB，
按 ESC 再按空白鍵進入遊戲。

您的電腦便如同您的手、眼和耳，可以用單字甚至整個句子來下達命令，除非螢幕上另有指示，
否則每個命令之後都要按 RETURN。

利用搖桿或鍵盤，可使格拉漢爵士往東、西、南、北和對角線來回移動，甚至某些時候要上、下
移動。如果您使用鍵盤控制，要停止時，只要再按一次剛才所按下的方向鍵即可。

## 肆、過關密訣（說明書原有提示）

1. 遊戲一開始，您便是格拉漢爵士，正站在王城的右邊。可以依前述的控制法操縱格拉漢爵士走過
   護城河上的橋樑（若不幸失足墜入護城河中，將為鱷魚吞食），找到城堡的入口後，打入
   `OPEN DOOR` 以打開城門，進皇宮去晉見愛德華國王。此時您可以輸入 `TALK TO KING`，
   國王便會向您述說三件寶物——魔鏡、靈盾和金盒子之魔力，並要求您去取回。如果您找齊了
   這三項寶物，國王就會將王位傳給您，因為您是戴凡確王國的救星，也只有您才有資格坐上王座。
2. 當您離開城堡，要開始探險時，請準備一支筆和一張紙，將每一步驟都作圖記錄下來。
   在 KING'S QUEST 遊戲內，可以畫出 8×6 的地域，其中有數十處藏有取寶的必需工具，也有些
   危險的區域，是需要特別註明的。同時，在您的探險過程中，得一邊回憶前面的故事，因為這一段
   歷史故事將有助於您找尋寶物。
3. 總之，每個方向都試試看，並將所有不同的機遇均繪製下來。如果您跳過了某個區域，則您可能
   錯過一項很重要的線索，或少掉一件必須的工具。您要走的路是既漫長又危險的，途中盤據了
   許多危險的妖魔鬼怪，您必須用您的智慧判斷，什麼時候該停下來戰鬥，什麼時候該逃跑，
   以避開兇暴的對手。但請放心，您可能在料想不到的地方獲得協助。
